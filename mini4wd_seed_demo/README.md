# AICHIP モーターコントロールGUI

これは、シリアルポート（COMポート）経由で "AI-CHIP"（ミニ四駆などの制御基板）を制御するために Processing で作成されたアプリケーションです。

デバイスへの接続、およびモーターの走行開始・停止を行うためのシンプルなGUIを提供します。

## 主な機能

* **シリアルポート接続:**
    * COMポート名（例: "COM4"）を指定するテキスト入力欄。
    * デバイスへ接続する「CONNECT」ボタン。
    * 接続を解除する「DISCONNECT」ボタン。
* **モーター制御:**
    * **STARTボタン:** プログラムされた走行シーケンスを開始します。
    * **STOPボタン:** モーターを即座に停止させます（Duty 0%）。
* **走行シーケンス:**
    * 「START」ボタンを押すと、モーターのDuty比が **30%** と **100%** の間で、一定時間ごとに自動で切り替わります。

## 依存ライブラリ（前提条件）

* **Processing**
    * このスケッチは Processing 4 での動作が推奨されています。
* **controlP5 ライブラリ**
    * GUIの構築に `controlP5` ライブラリを使用しています。
    * Processingのメニューバーから `スケッチ > ライブラリをインポート > Manage Libraries... > Libraries` を選択し、`controlP5` を検索してインストールしてください。

## 使用方法

1.  `mini4wd_seed_demo.pde` をProcessingで開きます。
2.  AI-CHIP デバイスをPCに接続します。
3.  ウィンドウ上部のテキストフィールドに、デバイスが認識されているCOMポート名（例: "COM7"）を入力します。
4.  **CONNECT** ボタンを押します。接続に成功すると、接続UIの枠の色が赤色に変わります。
5.  **START** ボタンを押すと、走行シーケンス（30%と100%の自動切り替え）が開始されます。
6.  **STOP** ボタンを押すと、走行が停止します。
7.  終了する際は **DISCONNECT** ボタンを押し、接続を解除します。

## ファイル構成

* **`mini4wd_seed_demo.pde`**
    * メインのスケッチファイル。UIのセットアップとイベント処理を行います。
* **`comPortConnection.pde`**
    * COMポート接続用UI（ボタン、テキストフィールド）を定義するクラスです。
* **`command.pde`**
    * AI-CHIPへ送信する10byteのシリアルコマンド（モーターDuty制御、LED制御など）を生成する関数群です。
